# CSC-461-001 – Assignment 3 VR Assembly by Daniel Novak

This project tasks the player with building Bonesy the Skeleton. There is a pit of skeleton bones, in which the player
must grab each bone and place it in the correct spots as given by the ghostly skeleton outline.
